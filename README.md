# servitorconnecthashing

ServitorConnect Hashing, which uses a manual hashing algorithm to generate powerful energy.<br>
You can set how many times to repeat per hour, albeit due to the algorithm used, it will do a lot of work regardless and be powerful.<br>
Based on Thomas Sweet/AnthroHeart/Cio's Intention Repeater work.

This is the library version. The interactive one is at https://reden777.github.io/servitorconnect/2SCNewHash.html
